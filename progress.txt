## Codebase Patterns
- Module name is `goomacs`, so term package imports as `goomacs/term`
- main.go uses term.Screen interface with term.KeyEvent, term.ResizeEvent, term.Style types
- Buffer struct holds Lines, CursorR/C, ScrollOffset, Modified, Filename, KillRing, Mark, UndoStack, Mode, ReadOnly
- Event loop in main.go: PollEvent → dispatch by mode (search/minibuffer/confirm/C-x prefix/buffer mode/normal) → redraw
- cell struct in terminal.go: {ch rune, style Style} — used for diff-based rendering in Show()
- Style is now a struct (fg Color, bg Color, reverse bool, bold bool); StyleDefault is a var, not const
- writeStyledCell() on Terminal emits combined ANSI sequence
- Highlighter in highlight.go: NewHighlighter(filename) → nil if no lexer; Highlight(lines) caches [][]term.Style; StyleAt(row,col) returns cached style
- drawWindowContent(screen, win, sh) renders buffer content in window's row range
- Tab expansion handled in rendering (bufColToVisualCol), tabWidth = 8
- Tab key (KeyTab) in normal mode is NOT handled — no tab insertion; only used for minibuffer completion
- Only grep buffer has ReadOnly=true; *Buffer List* is NOT read-only
- For read-only editing tests, use grep buffer via find-grep command
- `buf` is a local alias for `buffers[activeBufferIdx]`
- Window struct: Buffer, ScrollOffset, StartRow, Height, StartCol, Width; ViewHeight() = Height-1
- recalcWindows distributes space evenly; vertical (C-x 2) stacks top/bottom, horizontal (C-x 3) side-by-side
- splitMode global var: "vertical" or "horizontal"
- Minibuffer: minibufferMode, minibufferPrompt, minibufferInput ([]rune), minibufferCursorPos, minibufferCallback are package-level vars
- Minibuffer supports cursor movement (C-a, C-e, C-f, C-b), editing (C-d, C-k, Backspace), and Tab completion
- modeHandlers map[string]func(...) bool — buffer-local mode dispatch (currently: "grep")
- Command struct uses func(*Buffer, *string) signature; RegisterCommand in init(); FindCommand/FindCommandsByPrefix for lookup
- Registered commands: find-grep, comment-region, uncomment-region
- detectCommentStyle(filename, content) returns CommentStyle via go-enry language detection
- editorScreen (package-level in grep.go) allows goroutines to PostEvent to wake PollEvent
- grepResultCh channel + non-blocking select after event switch handles async grep results
- executeGrepCommand(cmd) launches goroutine, sends on grepResultCh, posts synthetic event
- buffers, activeBufferIdx, previousBufferIdx are package-level vars
- e2e/ directory contains 48 E2E tests; harness.go provides Harness struct for tmux-based testing
- Harness methods: Start, StartInDir, SendKeys, SendKeysRepeat, Capture, CaptureWithEscapes, CapturePane, WaitForContent, CursorPosition, Close
- Assertion helpers: AssertLineContains, AssertLineEquals, AssertStatusBar, AssertMessageLine, AssertScreenContains, AssertScreenSnapshot, AssertCursorAt
- For Alt keys in e2e tests, use tmux M-n/M-p syntax directly — do NOT use Escape + sleep + key
- grep -rnH output order is not alphabetical — pipe through | sort for predictable test assertions
- maxUndoEntries = 100 in buffer.go
- C-x prefix fallthrough: unmatched second key cancels prefix, then key is processed by normal dispatch
- Confirm mode only accepts 'y', 'n', C-g — all other keys silently ignored
- Search mode: unrecognized keys exit search and re-post via screen.PostEvent for normal processing
- Empty buffer invariant: always at least 1 empty line ([][]rune{{}}), never zero lines
